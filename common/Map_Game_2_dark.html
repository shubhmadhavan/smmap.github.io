Keyboard shortcuts

    Click a featureShow / hide its name (Alt+click keeps it painted)
    RReveal / hide every name
    T Ctrl+IShow notes inside the labels
    F4Open / close the list
    /Filter the list
    ↑ ↓ EnterMove through the list, highlight on the map
    WASDPan (Shift+A/D faster)
    F GZoom in / out (also Shift+W/S)
    ZChange label size
    IJKLNudge the label you last clicked
    Ctrl+1–4Grey / Green / Beige / default map
    Ctrl+HHome
    EscClose this / leave the full-screen list
